❯ what does this project do?                                                    

  Read 3 files (ctrl+o to expand)

⏺ ExpenseLY (branded "Spendly" in the UI) is a personal expense-tracking web app
  built in Flask, structured as a step-by-step student project.

  - Stack: Flask + Jinja2 templates, SQLite (via database/db.py), vanilla
    CSS/JS.
  - Current state: landing page, register, and login pages are built
    (templates/landing.html, register.html, login.html). Routes for logout,
    profile, and expense add/edit/delete exist as placeholders returning "coming
    in Step N" text.
  - database/db.py is a stub with comments describing what students are meant to
    implement: get_db(), init_db(), seed_db() — i.e., the SQLite schema/setup
    hasn't been written yet.
  - Intent: users register/log in, then log expenses (amount, category, date,
    description), see category breakdowns and monthly spending summaries, and
    filter by time period — per the landing page's marketing copy.

  So right now it's essentially the front-end shell + routing skeleton of an
  expense tracker, with auth and the actual expense CRUD/database logic still to
  be implemented (per the "Step 1", "Step 3", "Step 7-9" comments scattered
  through the code).
